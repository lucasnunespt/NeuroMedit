# Legendas das meditações

As legendas aparecem quando a pessoa liga **Configurações → Uso → Legendas**.
Cada áudio procura aqui um arquivo com o mesmo nome e a extensão `.vtt`:

| Áudio | Arquivo de legenda |
|---|---|
| audio/intro-v2.mp3 (pausa inicial) | legendas/intro-v2.vtt |
| assets/audio/respiracao-calma.mp3.m4a | legendas/respiracao-calma.vtt |
| audio/voltar-foco.m4a | legendas/voltar-foco.vtt |
| audio/meditacaoparadormir.m4a | legendas/meditacaoparadormir.vtt |
| assets/audio/medit.observador.MP3 | legendas/medit.observador.vtt |
| assets/audio/remember.your.value.mp3.mp3 | legendas/remember.your.value.vtt |
| assets/audio/return-to-yourself.mp3.mp3 | legendas/return-to-yourself.vtt |

## Formato (WebVTT)

```
WEBVTT

00:00:02.000 --> 00:00:06.500
Encontre uma posição confortável.

00:00:08.000 --> 00:00:12.000
Deixe o corpo ficar pesado.
```

Dica: frases curtas (até ~2 linhas) e um intervalo de silêncio entre elas
deixam a leitura no mesmo ritmo calmo da voz.
